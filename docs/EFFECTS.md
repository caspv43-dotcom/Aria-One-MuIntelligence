## Looks (presets)

A look is a named bundle of effects. Use as `--preset NAME` (or `-e 'preset:NAME'`).

| look | contains | what it's for |
| --- | --- | --- |
| `blockbuster` | teal_orange, halation, grain, vignette, letterbox | Teal & orange + halation + grain + vignette + 2.39:1 bars. |
| `cinematic` | cinematic_grade, halation, grain, vignette | Film look: cinematic curve + halation + grain + vignette. |
| `clean` | — | Just conform the footage (no look). Useful as a control strip. |
| `dream_trails` | soft_focus, ghost_trails, bloom, vibrance, grain | Ethereal: soft focus, bloom and long motion trails. |

## Spec syntax

```
bloom                        # effect with default parameters
bloom(sigma=22:opacity=0.6)  # with parameters (colon separated)
teal_orange+grain(level=10)  # several effects, combined with +
preset:cinematic             # a look
```

Effects are always applied in stage order (geometry -> grade -> blend ->
artifact -> light -> frame -> text), regardless of the order you write them.
